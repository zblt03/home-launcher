# home-launcher

Módulo de [TizenBrew](https://github.com/reisxd/TizenBrew) que abre la app Home (`HkTvHome01.Home`, de [hack-tv](https://github.com/GuillemCortesOvide/hack-tv)) ya instalada en la TV.

En TizenBrew añade el módulo `gh/zblt03/home-launcher` y, si quieres que se abra solo, actívalo en los ajustes de autolaunch.
